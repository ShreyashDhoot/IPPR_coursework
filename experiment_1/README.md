# Experiment 1

Notebook: IPPR_exp_1.ipynb

## Aim
Practice core image processing operations using OpenCV and NumPy.

## Covered Work
- Basic operations: read, display (BGR/RGB/gray), save-ready preview, negative, resize.
- Arithmetic operations on two images: add, subtract, multiply, divide.
- Geometric transforms: translation and scaling (rotation section present but empty in notebook).
- Synthetic image generation tasks:
  - 2x2 chessboard
  - diagonal separation image
  - 8x8 full chessboard
  - PRN digit images and concatenation
- Intensity transforms:
  - linear contrast stretching (piecewise)
  - gray-level slicing
  - histogram visualization before/after transform

## Libraries Used
- cv2
- numpy
- matplotlib

## Notes
- The notebook uses absolute image paths like D:/ippr/experiment_1/image.jpg.
- If running on another machine/folder, replace absolute paths with relative paths.

## How To Run
1. Open IPPR_exp_1.ipynb.
2. Ensure dependencies are installed (opencv-python, numpy, matplotlib).
3. Run cells top to bottom.
4. Keep required input images in this folder or update paths in cells.
